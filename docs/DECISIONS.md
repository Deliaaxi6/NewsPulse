# DECISIONS — 决策记录

> 格式：日期 | 决策 | 当时背景 | 替代方案 | 结果/后续

## 2026-08-10

### D1. 项目命名 NewsPulse
- 决策：项目名为 NewsPulse（新闻脉冲→情绪驱动）
- 背景：需要好记、表意、可打字的名称
- 替代：情绪引擎 / newsense / 风闻 FengWen
- 结果：用户选定

### D2. 技术栈 Python 全家桶
- 决策：Python 3.10+ + akshare + pandas + SQLite 弃用改纯CSV + crontab
- 背景：金融数据生态（akshare 内置新闻接口）；压倒性生态优势（Node.js 需手写爬虫）
- 替代：Node.js（金融生态弱）、现成框架（网络受限已否决）
- 结果：选定 Python 全家桶

### D3. 数据存储纯 CSV
- 决策：纯 CSV 目录（替代 SQLite）
- 背景：匹配 Python 新手学习、数据流人眼可读
- 替代：SQLite（查询强但不直观）
- 结果：选定纯 CSV；后续需要检索时按"先CSV后SQLite"升级路径

### D4. 交互模型邮件+CSV+命令
- 决策：无 Web UI，交互 = 每日邮件报告 + CSV 查看 + 手动命令触发
- 背景：单人学习型工具，降低部署面
- 结果：确认

### D5. 仪表盘形态=静态HTML报告（关键决策）
- 决策：保留"仪表盘"需求但实现为静态 HTML 报告文件（非实时 Web 服务）
- 背景：用户坚持保留仪表盘；实时 Web 服务需常驻进程+端口暴露+认证，安全面大
- 替代：Flask 常驻（复杂度+安全面上升）
- 结果：静态 HTML 报告（零安全面、零维护）；已写入愿望清单：后续需要时再评估实时版

### D6. 密钥生命周期
- 决策：服务器独立 secrets.json（chmod 600、不进 git、scp 加密传输、错误不打印密钥）
- 背景：遵循安全规范规则22，最小权限
- 替代：加密存储（程序需密码启动，复杂度上升）、Webhook（重新选型）
- 结果：选定，轮换=改文件即生效，吊销=重置授权码

### D7. 熔断触发条件
- 决策：3倍杠杆下市值跌超33%（归零）→ 清仓 + 邮件告警 + 停止自动交易
- 背景：规避"3倍杠杆教科书式爆仓"风险
- 结果：确认（核心安全阀）

### D8. 熔断恢复=自动恢复（防循环条件）
- 决策：熔断后自动恢复，但带防循环条件：冷却5个交易日 + 连续2日情绪分转正 + 恢复仅1倍杠杆起步
- 背景：用户选择自动恢复而非人工确认；无防循环条件会导致"熔断→反弹→再熔断"恶性循环
- 替代：人工确认恢复（安全优先但需人工介入）
- 结果：选定自动恢复+冷却条件（安全阀保留核心位置）

### D9. 成本对账=已有订阅不计入
- 决策：火山云服务器费用不计入本项目预算（边际成本 ¥0/月），不占用50元红线
- 背景：服务器为已有订阅，无论本项目与否都在付费
- 结果：确认；预算红线判定 = 本项目新增成本 ≤50元/月

### D10. 代码更新=git+手动
- 决策：git 管理 + 手动 ssh 执行 launcher.sh（拉取+重载）
- 背景：单人项目，自动化 pull 在失败时排查麻烦
- 替代：crontab 每日自动 pull（失败排查麻烦）、scp 覆盖（无版本管理）
- 结果：选定 git+手动

### D11. 已砍掉功能
- 决策：砍掉 Web 实时仪表盘（改静态报告）、Telegram 重写入 MVP、真实资金交易
- 背景：合规红线 + 服务器境内直连限制 + 学习定位
- 结果：确认

### D12. 数据源重定向
- 决策：国内新闻优先（东财/新浪/财联社），Telegram 与 Twitter/X 暂缓
- 背景：境内服务器直连、反爬与 ToS 风险
- 结果：确认；Twitter 优先级最低立即放弃
